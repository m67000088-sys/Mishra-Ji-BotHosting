🤖 Apna Bot Host Karo

ZIP upload karo, env variables daalo, Start dabao. Python aur Node.js dono chalte hain, 24/7 auto-restart ke saath.

📦 ZIP Uploadbot.py + requirements.txt (ya index.js + package.json). Libraries khud install hoti hain.
🔐 Env VariablesBOT_TOKEN jaisi secrets alag se, encrypted store hoti hain. Code mein token nahi.
♻️ Auto-restartCrash hone par bot khud wapas chalu, live logs aur CPU/RAM dikhta hai.
✈️ Telegram ReadyToken test button, aur ek token do bots mein chalne se pehle warning.

Left menu se Naya Bot kholo aur apna ZIP upload karo.

📤 Naya Bot Upload Karo

ZIP ke andar kya hona chahiye?

Dono me se ek tarah ka ZIP banao (files seedha top-level par, ya ek folder ke andar):

🐍 Python                 🟢 Node.js
bot.py                    index.js
requirements.txt          package.json

Token code mein mat likho. Upload ke baad ⚙️ Env mein BOT_TOKEN add karo aur code mein padho:

Python:  TOKEN = os.environ["BOT_TOKEN"]
Node:    const TOKEN = process.env.BOT_TOKEN

requirements.txt mein sirf PyPI packages (jaise python-telegram-bot==21.6) allowed hain. Single .py / .js file bhi upload ho jati hai.
